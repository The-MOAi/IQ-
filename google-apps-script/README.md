# 第2回 海外スタッフ研修 アンケートフォーム

このディレクトリには、Googleフォームを自動生成するための Google Apps Script が入っています。

## セットアップ手順

1. [Google Apps Script](https://script.google.com) を開く
2. 「新しいプロジェクト」をクリック
3. `createSurveyForm.gs` の内容をコピー&ペースト
4. 上部メニューから関数 `createSurveyForm` を選択
5. 「実行」をクリック
6. 初回実行時に Google アカウントへのアクセス許可を求められるので承認
7. 実行ログ（`Ctrl + Enter` または 表示 → ログ）に以下が出力されます:
   - 編集用URL
   - 回答用URL
   - 短縮URL

## フォーム仕様

| 項目 | 内容 |
|---|---|
| タイトル | 第2回 海外スタッフ研修 アンケート |
| 回答制限 | 1人1回まで |
| メール収集 | なし |
| ログイン要求 | なし（誰でも回答可） |
| 進捗バー | あり |
| 質問順 | 固定（シャッフルなし） |
